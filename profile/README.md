# World Meteorological Organization (WMO)

The WMO GitHub organization provides a shared, discoverable home for Free Open Source Software developed by WMO and its Members in support of WMO-sponsored scientific and technical programs and has been initially populated with software developed in support of WIS2 implementation.

For more information, see the [WMO Guide to Free and Open Source Software](https://wmo-im.github.io/wmo-foss-guide/guide/wmo-foss-guide-DRAFT.html) (INFCOM-4-Draft)
